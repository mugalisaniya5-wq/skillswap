# SkillSwap

SkillSwap is a platform where users can share their skills and learn new skills from others.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Simple and user-friendly interface
- Skill sharing and learning
- Interactive website design

## Project Files
- index.html

- script.js

## How to Run
